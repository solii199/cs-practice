Отличие git diff от git show и git log в том, что: git diff показывает изменения до команды git add,
 git show отображает информацию об одном коммите, а git log отображает список коммитов, которые зафиксированны в репозитории
log -S он ищет коммиты, в котором были изменения с указанным в команде словом.
Команда  blame показывает в каком именно коммите строка изменилась и кто ее изменил
Отличие git restore от git restore --source=... в том что git restore возвращает к состоянию последнего коммита,
 а git restore --source=... возвращает к конкретному коммиту, который мы задали
