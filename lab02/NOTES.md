Рабочая папка - это папка на компьютере, там лежат файлы какого-либо проекта, где пользователь может редактировать их

Индекс - это зона где хранятся изменения, которые пользователь подготовил для следующего коммита

Коммит - это сохраненное состояние проекта в определенный момент времени

Различие Git и Github. Git - это инструмент для контроля версий, программа которая отслеживает изменения в коде.
Github - это сайт,  где хранятся проекты, созданные в Git. 

Использованные команды: git status - текущее состояние репозитория. git diff - показывает как изменились строки, сравнивая с тем, что было до. git diff --staged это готовые изменения для коммита.

Ветки: Ветка -  это линия разработки, которая позволяет изменять код, не затрагивая основной проект. При новом коммите ветка в Git передвигается вперед и начинает указывать на этот новый коммит. Слияние веток - это процесс обьединения изменений из одной ветки в другую.
